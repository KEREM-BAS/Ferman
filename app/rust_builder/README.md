# rust_lib_ferman

A Flutter FFI plugin with no Dart code: its only job is to build the Ferman engine
(`crates/ferman-api`, with the `frb` feature) through [cargokit](cargokit/README) and bundle the
library with the app on macOS, Windows and Linux. The Dart bindings live in `app/lib/bridge/`
(generated by flutter_rust_bridge 2.13.0) and are imported only by `app/lib/engine/`.

`cargokit/` is vendored from flutter_rust_bridge 2.13.0's integration template (MIT OR Apache-2.0,
see `cargokit/LICENSE`) with two changes, each marked "Ferman patch":

- `cargokit/build_tool/lib/src/builder.dart`: it builds with the toolchain pinned in the
  repository's `rust-toolchain.toml` instead of always using `stable`.
- `cargokit/build_tool/lib/src/cargo.dart` (`libraryName`) and the files that use it: it looks for
  the library under cargo's name, with `-` turned into `_` (the package `ferman-api` builds
  `libferman_api`).

Precompiled binaries are not configured, so the build tool never downloads an engine library; it
always builds from source. Its own Dart dependencies (pinned in `cargokit/build_tool/pubspec.yaml`)
are fetched from pub.dev at the first native build and never ship with the app.
