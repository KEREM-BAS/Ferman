# rust_lib_ferman

A Flutter FFI plugin with no Dart code: its only job is to build the Ferman engine
(`crates/ferman-api`, with the `frb` feature) through [cargokit](cargokit/README) and bundle the
library with the app on macOS, Windows and Linux. The Dart bindings live in `app/lib/bridge/`
(generated by flutter_rust_bridge 2.13.0) and are imported only by `app/lib/engine/`.

`cargokit/` is vendored from flutter_rust_bridge 2.13.0's integration template (MIT OR Apache-2.0,
see `cargokit/LICENSE`) with one change, marked "Ferman patch" in
`cargokit/build_tool/lib/src/builder.dart`: it builds with the toolchain pinned in the repository's
`rust-toolchain.toml` instead of always using `stable`.
